What is CSS?

CSS (Cascading Style Sheets) is the language used to design and style web pages. While HTML creates the basic structure of a website, CSS controls how it looks—including colors, fonts, spacing, and page layouts.

3 Ways to Add CSS

You can connect CSS to your HTML document in three ways:

  • Inline CSS: Written directly inside an HTML tag using the style attribute.
  • Internal CSS: Written inside a <style> tag in the <head> section of an HTML file.
  • External CSS (Best Practice): Written in a separate .css file and linked using the <link> tag.

Real-Life Example: Building a House

Think of building a website like building a house:

  • HTML is the bricks, cement, and walls (the basic structure).
  • CSS is the paint, tiles, and decoration (what makes it look beautiful).

Selectors

CSS selectors are patterns used to select the elements you want to style. They can target elements by tag name, class, ID, attributes, and more. Selectors are the foundation of CSS, allowing you to apply styles to specific parts of your HTML.

Common Selectors

  • Element Selector: Selects all elements of a type.
    Example: p { color: blue; }
  • Class Selector: Selects elements with a specific class.
    Example: .highlight { background-color: yellow; }
  • ID Selector: Selects a single element with a specific ID.
    Example: #header { font-size: 24px; }
  • Attribute Selector: Selects elements based on an attribute value.
    Example: [type="text"] { border: 1px solid #ccc; }

Pseudo-classes and Pseudo-elements

Pseudo-classes and pseudo-elements allow you to style elements based on their state or position.

  • :hover - Styles an element when the user moves their mouse pointer over it.

    Example: button:hover { background-color: yellow; }

    (Explanation: When a user places their mouse cursor over a <button>, its background color will immediately change to yellow.)
  • :active - Styles an element at the exact moment it is being clicked.

    Example: button:active { transform: scale(0.95); }

    (Explanation: While the user is pressing down the mouse button on a <button>, it will slightly shrink to give a real click effect.)
  • :focus - Styles an input field when the user clicks inside it or selects it using the Tab key.

    Example: input:focus { border-color: blue; }

    (Explanation: When a user clicks inside an <input> box to type, its border will turn blue.)
  • :nth-child(n) - Selects and styles a specific child element based on its position (number) inside a parent.

    Example: li:nth-child(2) { font-weight: bold; }

    (Explanation: If you have multiple <li> tags inside a <ul>, this CSS will apply only to the 2nd <li> item.)
  • :last-child - Selects and styles only the very last child element inside a parent.

    Example: li:last-child { color: red; }

    (Explanation: If you have multiple <li> tags inside a <ul>, this CSS will apply only to the very last <li> item.)
  • :not(selector) - Selects and styles every element except the ones that match the specified selector.

    Example: li:not(.active) { color: gray; }

    (Explanation: If you have multiple <li> tags inside a <ul>, this CSS will apply to all <li> items except the one with class="active".)
  • :first-of-type - Selects and styles the very first element of a specific tag type inside a parent.

    Example: p:first-of-type { color: green; }

    (Explanation: If a <div> has an <h1> followed by multiple <p> tags, this CSS will apply only to the very first <p> tag, even if it is not the first child overall.)
  • :last-of-type - Selects and styles the very last element of a specific tag type inside a parent.

    Example: p:last-of-type { color: purple; }

    (Explanation: If a <div> has multiple <p> tags followed by a <button>, this CSS will apply only to the very last <p> tag, even if it is not the last child overall.)
  • :first-child - Selects and styles only the very first child element inside a parent.

    Example: li:first-child { color: blue; }

    (Explanation: If you have multiple <li> tags inside a <ul>, this CSS will apply only to the very first <li> item.)
  • ::before - Adds extra content (like text, icons, or shapes) right before an element's actual content.

    Example: p::before { content: "Note: "; color: red; }

    (Explanation: If you have a <p> tag, this CSS will automatically place the red word "Note: " in front of your paragraph text without changing the HTML.)
  • ::after - Adds extra content (like text, icons, or shapes) right after an element's actual content.

    Example: p::after { content: " (Read more)"; color: blue; }

    (Explanation: If you have a <p> tag, this CSS will automatically place the blue text " (Read more)" at the very end of your paragraph without changing the HTML.)
  • ::first-letter - Styles only the very first letter of a block of text.

    Example: p::first-letter { font-size: 32px; color: red; }

    (Explanation: In any <p> paragraph, only the very first alphabet will become large and red, just like in a newspaper or storybook.)
  • ::placeholder - Styles the hint text inside an input field before the user types anything.

    Example: input::placeholder { color: gray; font-style: italic; }

    (Explanation: The temporary hint text inside an <input> box (like "Enter your name") will appear in gray and italic.)
Colors and Backgrounds

CSS allows you to set colors for text, backgrounds, borders, and more. You can use color names, HEX codes, RGB values, or HSL values.

Text Color

Use the color property to change text color.

Example: p { color: blue; }

Background Color

CSS background properties let you add solid colors, images, or smooth color gradients behind any HTML element.

1. Background Color: Use background-color to fill an element with a solid color. You can use color names, HEX codes, or RGB values.

.box {
                      background-color: #1e293b;  /* Sets a dark blue-grey background color */
                 }

2. Background Image: Use background-image with url() to place a picture behind an element.

.hero-banner {
              background-image: url("banner.jpg");  /* Adds an image from your folder or a link */
            }

3. Adjusting the Image: After adding an image, use these properties to make it fit neatly:

  • background-repeat: Stops the image from tiling or repeating (use no-repeat).
  • background-size: Controls the image size. cover stretches it to fill the whole box without distortion.
  • background-position: Moves the image to the center, top, or bottom.
  • background-attachment: Keeps the image fixed in place while scrolling (fixed) or scrolls with the content (scroll).
.hero-banner {
  background-image: url("banner.jpg");  /* Sets the background image */
  background-repeat: no-repeat;         /* Prevents the image from repeating */
  background-size: cover;               /* Scales the image to cover the full area */
  background-position: center;          /* Centers the image inside the box */
}

4. Linear Gradient: Use linear-gradient() to smoothly blend two or more colors together without using an image file.

.gradient-card {

  /* Blends blue into purple from left to right (90deg) */

  background: linear-gradient(90deg, #3b82f6, #8b5cf6);
}
The Box Model

Every HTML element is a rectangular box. The CSS box model describes how the size of that box is calculated, including its content, padding, border, and margin.

Box Model Components

  • Content: The actual text, image, or other media inside the box.
  • Padding: The space between the content and the border. It creates breathing room inside the box.
  • Border: A line that wraps around the padding and content. You can style it with width, color, and type (solid, dashed, etc.).
  • Margin: The space outside the border that separates this box from other elements.

Example

.box {
            width: 200px;             /* Width of the content area */
            padding: 20px;            /* Space inside the box */
            border: 5px solid black;  /* Border around the box */
            margin: 10px;             /* Space outside the box */

          
          }
Note: The total width of the box will be the sum of its width, padding, and border.

(Total Width = Content Width + Padding + Border)

200px + 20px + 20px + 5px + 5 Margin is not included in the box's width calculation.
Typography

Typography in CSS refers to the art and technique of styling text on a webpage. It includes choosing the right font, setting text sizes, adjusting spacing, and controlling text alignment.

Good typography makes your website easy to read, creates a visual hierarchy, and improves the overall user experience across different screen sizes.

Common Typography Properties

  • font-family: Specifies the typeface (font style) for text. You should always provide fallback fonts in case the first font fails to load.
    Example: font-family: 'Segoe UI', Arial, sans-serif;

    (Note: Always end with a generic family name like sans-serif or serif.)

  • font-size: Sets the size of the text. You can use fixed units like px or responsive units like rem and em.
    Example: font-size: 16px;

    (Note: 1rem is usually equal to 16px in most modern browsers.)

  • font-weight: Controls how thick or thin the characters in text should be displayed.
    Example: font-weight: bold;

    (Common values: normal (400), bold (700), or numbers from 100 to 900.)

  • line-height: Adjusts the vertical space between lines of text to improve readability.
    Example: line-height: 1.5;

    (Note: Using a unitless number like 1.5 is recommended because it scales automatically with the font size.)

  • letter-spacing: Increases or decreases the horizontal space between individual characters.
    Example: letter-spacing: 2px;

    (Tip: Slightly positive spacing works great for uppercase headings.)

  • text-decoration: Adds or removes decorative lines on text, such as underlines, overlines, or strikethroughs.
    Examples: text-decoration: none; text-decoration: underline; text-decoration: overline; text-decoration: line-through;

    (Note: Setting it to none is most commonly used to remove default underlines from <a> links.)

  • text-align: Controls the horizontal alignment of text inside its container.
    Example: text-align: center;

    (Common values: left, right, center, and justify.)

Positioning

The position property in CSS controls how an element is placed on a webpage and how it interacts with the normal document flow (the default layout order of HTML elements).

Depending on the position value you choose, an element either keeps its original space reserved on the page or gets completely removed from the flow, allowing other elements below it to move up and fill the empty gap.

Position Values and Document Flow

  • position: static; This is the default value for all HTML elements. Elements follow the normal document flow from top to bottom.
    Example: div { position: static; }

    (Behavior: The element stays in its natural spot, and properties like top, bottom, left, or right have no effect.)

  • position: relative; Moves the element relative to its own original starting position without removing it from the document flow.
    Example: .box { position: relative; top: 20px; left: 30px; }

    (Space Behavior: When the element moves, its original space stays reserved (empty). Elements below it do NOT move up to fill the gap, so the moved element may overlap neighboring content.)

  • position: absolute; Completely removes the element from the normal document flow and positions it relative to its nearest positioned ancestor (an ancestor with relative, absolute, fixed, or sticky).
    Example: .badge { position: absolute; top: 10px; right: 10px; }

    (Space Behavior: Because it is lifted out of the normal flow, no empty space is left behind. All elements below it immediately shift up to take its original place.)

  • position: fixed; Removes the element from the normal document flow and locks it relative to the browser window (viewport). It stays in the exact same spot even when the user scrolls.
    Example: #navbar { position: fixed; top: 0; left: 0; width: 100%; }

    (Space Behavior: Just like absolute, it leaves zero empty space behind in the layout. Content below it moves up to the top, which is why you often need to add margin-top or padding-top to the main body so content doesn't hide underneath a fixed navbar.)

  • position: sticky; Acts like relative at first, and switches to fixed once the user scrolls past a specified threshold (like top: 0).
    Example: .sticky-header { position: sticky; top: 0; }

    (Space Behavior: Its original space always remains preserved in the document flow, so elements below it never jump up unexpectedly when it sticks.)

  • z-index: Controls the vertical stacking order (front-to-back) when positioned elements overlap each other.
    Example: .popup { position: absolute; z-index: 10; }

    (Note: An element with a higher z-index sits on top of elements with a lower number. It only works on elements that have a position other than static.)

Quick Summary: Position Comparison

Position Value Stays in Document Flow? Original Space Reserved? Elements Below Shift Up? Positioned Relative To
static Yes Yes No Normal page flow
relative Yes Yes (Empty gap remains) No Its own original spot
absolute No No (Removed from flow) Yes (Moves up immediately) Nearest positioned ancestor
fixed No No (Removed from flow) Yes (Moves up immediately) Browser window (viewport)
sticky Yes Yes (Space stays intact) No Scroll container & viewport
Flexbox

CSS Flexbox (Flexible Box Layout) is a layout system used to arrange, align, and distribute space among items inside a container.

To activate Flexbox, you add display: flex; to a parent container, which immediately places all its direct child elements side-by-side in a flexible row.

Common Flexbox Properties

  • flex-direction: Defines the direction in which items are placed inside the container. By default, it is set to row (horizontal, left to right), so you do not need to write anything if you want a normal row.
    Examples: flex-direction: row; flex-direction: column;

    (Note: row places items horizontally from left to right, while column stacks items vertically from top to bottom. You can also use row-reverse and column-reverse.)

  • justify-content: Aligns flex items along the main axis. When direction is row, it moves items horizontally (left to right); when direction is column, it moves items vertically (top to bottom).
    Examples: justify-content: center; justify-content: space-between; justify-content: space-around; justify-content: flex-end;

    (Note: Other values include flex-start and space-evenly. If direction is column, the parent needs a height to move items vertically.)

  • align-items: Aligns flex items along the cross axis (the opposite direction of justify-content). When direction is row, it moves items up and down, so the parent container must have a defined height.
    Example: .container { display: flex; height: 200px; justify-content: center; align-items: center; }

    (Important: Without justify-content: center, items stay on the left side when centered vertically. Also, if flex-direction is column, align-items moves items left and right instead of up and down. Common values are center, flex-start, flex-end, and stretch.)

  • flex-wrap: Controls whether flex items stay squeezed onto one single line or wrap onto the next line when there is not enough space.
    Examples: flex-wrap: nowrap; flex-wrap: wrap;

    (Note: nowrap is the default, which forces all items to shrink and stay on one line. Using wrap pushes extra items onto the next line automatically.)

  • flex-flow: A shorthand property that lets you write both flex-direction and flex-wrap together in one line.
    Examples: flex-flow: row wrap; flex-flow: column nowrap;

    (Syntax: flex-flow: [flex-direction] [flex-wrap];)

  • gap: Adds clean, equal space between flex items without needing extra margins on each box.
    Example: gap: 15px;

    (Tip: You can also use row-gap and column-gap separately.)

  • align-content: Aligns multiple wrapped lines of items when there is extra vertical space in the container.
    Example: align-content: space-between;

    (Note: This property only works when flex-wrap: wrap; is active and there are two or more rows of items.)

  • flex (Child Item Property): Applied directly to a child item (not the parent) to control how much it can grow or shrink to fill extra space.
    Example: .box-1 { flex: 1; }

    (Note: flex: 1 is shorthand for flex-grow, flex-shrink, and flex-basis, allowing items to expand equally.)

  • order (Child Item Property): Changes the visual order of individual flex items without changing the HTML code.
    Example: .first-box { order: 2; }

    (Note: Default order for all items is 0. Lower numbers appear first, and higher numbers appear later.)

CSS Grid

CSS Grid Layout is a two-dimensional layout system that lets you arrange items into both rows and columns at the same time. While Flexbox works best in one direction at a time, Grid is ideal for building complete webpage layouts (like header, sidebar, main content, and footer).

To start using Grid, you apply display: grid; to a parent container, which turns all its direct children into grid items.

Common CSS Grid Properties

  • display: grid; Activates the Grid layout on a parent container so you can create rows and columns inside it.
    Example: .container { display: grid; }

    (Note: By itself, display: grid; keeps items stacked in a single column until you define column sizes.)

  • grid-template-columns: Defines the number of columns and the width of each column in your grid layout.
    Examples: grid-template-columns: 1fr 1fr 1fr; grid-template-columns: 250px 1fr; grid-template-columns: repeat(3, 1fr);

    (Note: The fr unit stands for "fraction" of the available space. In 1fr 1fr 1fr, the page is divided into 3 equal parts. In 250px 1fr, the sidebar gets 250px and the main content automatically takes up the rest of the screen. You can also use repeat(3, 1fr) as a shortcut for three equal columns.)

  • grid-template-rows: Defines the height of each horizontal row in your grid.
    Examples: grid-template-rows: 80px 1fr 60px; grid-auto-rows: minmax(150px, auto);

    (Note: In 80px 1fr 60px, the header gets 80px, footer gets 60px, and the middle content takes the remaining height. Use grid-auto-rows to automatically set height for extra rows.)

  • grid-template-areas: Lets you design an entire webpage layout visually using custom names for each section (like header, sidebar, main, and footer).
    Example: .page { display: grid; grid-template-areas: "header header" "sidebar main" "footer footer"; } .header { grid-area: header; }

    (Note: Each string inside quotes represents one row. Repeating a name like "header header" makes that section stretch across two columns.)

  • gap: Sets clean spacing between grid rows and columns without adding outer margins or causing horizontal scrollbars.
    Examples: gap: 20px; gap: 15px 30px;

    (Note: One value sets equal spacing for both rows and columns. Two values set row-gap first and column-gap second.)

  • grid-column & grid-row: Applied to child grid items to make a single box stretch (span) across multiple columns or rows.
    Examples: .banner { grid-column: 1 / -1; } .featured-card { grid-column: span 2; grid-row: span 2; }

    (Note: Using 1 / -1 stretches an item across the full width of the page from the first line to the very last line, while span 2 makes it take up 2 columns or rows.)

  • place-items: A shorthand property that aligns content both vertically and horizontally inside every grid cell at once.
    Example: .container { display: grid; place-items: center; }

    (Note: It combines align-items and justify-items, making it the fastest way in CSS to dead-center any element.)

  • Responsive Grid (auto-fit & minmax): Automatically adjusts the number of columns based on screen size without needing media queries.
    Example: grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

    (Note: Each card stays at least 250px wide and automatically wraps onto a new row on smaller mobile screens.)

Transitions

CSS Transitions allow you to change property values smoothly over a given duration instead of having them happen instantly. They are most commonly used with hover effects (like changing a button's background color or size when a user moves their mouse over it).

To create a transition effect, you must specify at least two things: the CSS property you want to animate and the duration of the effect.

Common CSS Transition Properties

  • transition-property: Specifies the exact CSS property (or properties) you want to animate when a change occurs.
    Examples: transition-property: background-color; transition-property: all;

    (Note: Using all animates every property that changes on hover, though naming specific properties like transform or opacity gives better performance.)

  • transition-duration: Defines how long the transition animation takes to complete. It is written in seconds (s) or milliseconds (ms).
    Examples: transition-duration: 0.3s; transition-duration: 500ms;

    (Note: If you do not set a duration, the default value is 0s, which means no smooth transition will happen. For buttons and links, 0.2s to 0.4s feels the most natural.)

  • transition-timing-function: Controls the speed curve of the transition, deciding whether it starts slow, moves at a constant speed, or slows down at the end.
    Examples: transition-timing-function: ease; transition-timing-function: linear; transition-timing-function: ease-in-out;

    (Note: ease is the default (starts slow, speeds up, then ends slow). linear keeps the exact same speed from start to finish, while ease-in-out gives a smooth slow start and slow end.)

  • transition-delay: Sets a waiting time before the transition effect actually begins after the user triggers it (such as hovering).
    Example: transition-delay: 0.5s;

    (Note: Useful when you want multiple elements to animate one after another in a sequence rather than all at the exact same moment.)

  • transition (Shorthand Property): Lets you write all four transition properties together in a single, clean line of CSS.
    Examples:
    .btn { transition: background-color 0.3s ease 0s; }
    .btn:hover { background-color: #0b5394; }

    (Note: Always put the transition property on the normal base element (like .btn) and NOT inside :hover. Putting it on the base element ensures the animation plays smoothly both when the mouse enters and when it leaves.)

  • transition (Shorthand Property): Lets you write all four transition properties together in a single line instead of writing them separately.
    Syntax & Examples: /* Syntax: transition: property duration timing-function delay; */ .btn { transition: background-color 0.3s ease 0s; } .btn { transition: all 0.3s ease-in-out; } .card { transition: transform 0.3s ease, box-shadow 0.4s linear; }

    (Note: Only property and duration are required—if you skip timing-function and delay, CSS uses default values automatically. You can also animate multiple properties at once by separating them with a comma. Always place transition on the base element, not on :hover, so it animates smoothly both in and out.)

    • Animations

    CSS Animations allow you to animate elements smoothly from one style to another without needing JavaScript. Unlike transitions (which require a trigger like :hover), animations can start automatically as soon as the page loads and can loop forever.

    To create a CSS animation, you need two parts: a @keyframes rule (which defines the steps of the animation) and animation properties applied to the HTML element.

    Common CSS Animation Properties & Concepts

    • @keyframes Rule (Defining Steps): Controls what happens at different stages of the animation using from / to or percentage steps (0%, 50%, 100%).
      Example (Fade & Slide In): @keyframes slideIn { 0% { opacity: 0; transform: translateY(30px); } 100% { opacity: 1; transform: translateY(0); } }

      (Note: 0% is the starting style and 100% is the ending style. You can add middle steps like 50% to change direction, color, or size halfway through.)

    • animation-name & animation-duration: Connects the @keyframes rule to your element and sets how long one full cycle of the animation takes.
      Example: .box { animation-name: slideIn; animation-duration: 1.5s; }

      (Note: Without animation-duration, the default is 0s and the animation will not play at all.)

    • animation-iteration-count: Sets how many times the animation should repeat. You can give a specific number or use infinite to make it run forever.
      Examples: animation-iteration-count: 3; animation-iteration-count: infinite;

      (Note: Use infinite for loading spinners, pulsing buttons, and floating icons.)

    • animation-direction & animation-fill-mode: Controls whether the animation plays forward, backward, or alternates back-and-forth, and whether it keeps its final style after finishing.
      Examples: animation-direction: alternate; animation-fill-mode: forwards;

      (Note: alternate makes an element bounce smoothly back and forth (0% to 100%, then 100% back to 0%). forwards stops the element from snapping back to its original position after the animation ends.)

    • animation (Shorthand Property): Combines all animation settings into a single, clean line of CSS.
      Syntax & Example: /* Syntax: animation: name duration timing-function delay iteration-count direction fill-mode; */ .hero-text { animation: slideIn 1s ease-out 0.2s 1 normal forwards; }

      (Note: You only need name and duration at minimum; any skipped values automatically use their defaults.)

    • Creating Specific Animations (Circle Spinner, Bounce & Pulse): By combining @keyframes with transform and border-radius, you can build popular UI effects.
      1. Circle Loading Spinner (360° Rotation): .spinner { width: 50px; height: 50px; border: 5px solid #ddd; border-top-color: #0b5394; border-radius: 50%; animation: spin 1s linear infinite; } @keyframes spin { 100% { transform: rotate(360deg); } }

      (How Circle Spinner Works: Giving equal width and height with border-radius: 50% creates a circle. Coloring only border-top-color and rotating 360deg with linear infinite makes a smooth loading wheel.)

      2. Bouncing Ball / Icon (Up & Down): .ball { width: 40px; height: 40px; border-radius: 50%; animation: bounce 0.6s ease-in-out infinite alternate; } @keyframes bounce { 0% { transform: translateY(0); } 100% { transform: translateY(-25px); } }

      (How Bounce Works: Moving the circle up with translateY(-25px) and using infinite alternate makes it jump up and fall down smoothly forever.)

      3. Pulse / Heartbeat Effect (Zoom In & Out): .pulse-btn { animation: pulse 1.2s ease-in-out infinite alternate; } @keyframes pulse { 0% { transform: scale(1); } 100% { transform: scale(1.15); } }

      (How Pulse Works: scale(1.15) grows the element by 15% and shrinks it back to normal size, great for notification badges or call-to-action buttons.)

    Media Queries

    CSS Media Queries are used to make websites responsive, meaning the layout automatically adjusts to look clean and readable on all screen sizes—from small mobile phones to tablets and wide laptop screens.

    Using the @media rule, you can apply specific CSS styles only when the browser screen matches certain conditions like width, height, or device orientation.

    Media Query Concepts & Breakpoints

    • @media Rule (Basic Syntax): Wraps your responsive CSS rules inside curly braces so they only activate when a screen size condition is true.
      Example: @media (max-width: 768px) { body { font-size: 14px; } }

      (Note: Remember to always include <meta name="viewport" content="width=device-width, initial-scale=1.0" /> inside your HTML <head> tag, otherwise mobile browsers will zoom out and ignore media queries.)

    • max-width (Desktop-First Approach): Applies styles when the screen width is equal to or smaller than the given value. It acts as an upper limit ("up to this size").
      Example: @media (max-width: 600px) { .container { flex-direction: column; } }

      (How max-width Works: Any screen from 0px up to 600px (mobile phones) will stack items in a column. Once the screen becomes wider than 600px, this rule turns off automatically.)

    • min-width (Mobile-First Approach): Applies styles when the screen width is equal to or larger than the given value. It acts as a starting limit ("from this size and above").
      Example: @media (min-width: 769px) { .grid { grid-template-columns: repeat(3, 1fr); } }

      (How min-width Works: This rule stays off on small mobile screens and activates only when the screen reaches 769px or wider (tablets and laptops).)

    • Combining min-width & max-width (Target Specific Devices): You can use the and keyword to target an exact range of screen sizes, such as tablets only.
      Example: @media (min-width: 601px) and (max-width: 1024px) { .cards { grid-template-columns: repeat(2, 1fr); } }

      (Note: This rule applies strictly between 601px and 1024px, leaving phones below 601px and large laptops above 1024px unaffected.)

    • Standard Screen Sizes (Mobile, Tablet & Laptop Views): Developers use common screen width breakpoints to design layouts for different devices.
      Common Device Breakpoints: /* Mobile Phones: 320px to 600px */ /* Tablets (iPad): 601px to 1024px */ /* Laptops & Desktops: 1025px and above */

      (How Views Change: On Mobile View, sidebars move to the top, multi-column grids become 1 single column, and font sizes get slightly smaller. On Laptop View, sidebars stay fixed on the left and content spreads across 2 to 4 columns.)

    • Responsive Navbar Example (freeCodeCamp Project Layout): Moves a fixed left sidebar to the top of the screen on mobile devices so the content has enough room to read.
      Example: @media (max-width: 768px) { #navbar { position: relative; width: 100%; height: auto; } #main-doc { margin-left: 0; } }

      (Note: Always write your @media queries at the very bottom of your CSS file so they properly override your main desktop styles.)

    CSS Variables

    CSS Variables (officially called Custom Properties) allow you to store reusable values—such as colors, font sizes, or spacing—in one place and reuse them throughout your entire stylesheet.

    Using variables makes your CSS code much easier to maintain. If you ever want to change your website's main theme color, you only need to update the variable value once instead of editing hundreds of lines of code.

    CSS Variable Rules & Concepts

    • :root Selector (Global Variables): Declares variables at the highest level of the webpage (the <html> element) so they can be accessed and used anywhere in your CSS file.
      Example: :root { --primary-color: #0b5394; --bg-color: #ffffff; --main-padding: 16px; }

      (Note: Every CSS variable name must start with two dashes (--), and variable names are case-sensitive, meaning --main-color and --Main-Color are treated as two different variables.)

    • var() Function (Using Variables): Inserts the stored value of a custom property into any normal CSS rule.
      Examples: body { background-color: var(--bg-color); } h1 { color: var(--primary-color); padding: var(--main-padding); }

      (Note: You can use var() for colors, pixel sizes, fonts, shadows, or any valid CSS value.)

    • Fallback Values (Backup Value): Lets you provide a second backup value inside var() in case the main variable is not defined or has a typo.
      Example: button { background-color: var(--btn-color, #007bff); }

      (How it works: If --btn-color exists, the browser uses it. If --btn-color is missing, the browser safely falls back to #007bff instead of breaking the design.)

    • Local Variables (Scoped to One Element): Variables declared inside a specific class or element (instead of :root) only work inside that element and its children.
      Example: .alert-box { --box-color: #d9534f; border: 2px solid var(--box-color); color: var(--box-color); }

      (Note: Trying to use var(--box-color) outside of .alert-box will not work because it is a local variable.)

    • Easy Dark Mode / Theme Switching: Because CSS variables update live in the browser, you can switch an entire website from Light Theme to Dark Theme just by redefining the variables inside a dark class.
      Example: :root { --bg: #ffffff; --text: #222222; } body.dark-theme { --bg: #121212; --text: #f5f5f5; } body { background-color: var(--bg); color: var(--text); }

      (Note: Whenever the dark-theme class is added to <body>, every element using var(--bg) and var(--text) automatically switches colors at once.)

    CSS Units

    CSS Units are used to define sizes for properties like width, height, font-size, padding, and margin. They are divided into two main categories: Absolute Units (fixed sizes) and Relative Units (flexible sizes that adapt to screen or font changes).

    Choosing the right CSS unit is very important for building responsive websites that look great on both small mobile screens and large desktop monitors.

    Common CSS Units

    • px (Pixels — Absolute Unit): A fixed size unit that stays the exact same regardless of screen size or parent container width.
      Examples: border: 2px solid #0b5394; border-radius: 8px;

      (Note: Because px is fixed, it does not scale automatically on different screens. It is best used for small details like borders, shadows, and rounded corners, rather than large page widths.)

    • % (Percentage — Relative to Parent): Sets a size relative to the size of the element's parent container.
      Example: .child-box { width: 50%; }

      (How it works: If the parent container is 800px wide, 50% makes the child box 400px wide. If the parent shrinks on mobile, the child shrinks automatically too.)

    • rem (Root EM — Relative to Root HTML Font Size): Scales relative to the font size of the root <html> element, making your entire page's typography and spacing consistent and accessible.
      Examples: h1 { font-size: 2rem; } p { font-size: 1rem; margin-bottom: 1.5rem; }

      (Note: By default in most browsers, 1rem = 16px, so 2rem = 32px and 0.5rem = 8px. Using rem for font sizes is a best practice because it respects the user's browser zoom and font settings.)

    • em (Relative to Parent Font Size): Scales relative to the font-size of its direct parent element (or its own font size if used for padding/margin).
      Example: .btn { font-size: 16px; padding: 0.5em 1.2em; }

      (Note: In this button example, 0.5em equals 8px and 1.2em equals 19.2px. If you increase the button's font-size later, the padding grows automatically with it.)

    • vw & vh (Viewport Width & Viewport Height): Sets sizes relative to the visible browser window (screen) size, where 1vw = 1% of screen width and 1vh = 1% of screen height.
      Examples: .hero-banner { width: 100vw; height: 100vh; } .half-screen { height: 50vh; }

      (Note: 100vh makes a section cover the entire visible screen height from top to bottom, which is very popular for full-screen landing page hero sections.)
