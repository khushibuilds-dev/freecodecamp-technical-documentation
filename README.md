# CSS Technical Documentation Page

A responsive **Technical Documentation Page** built with **HTML5** and **CSS3** as part of the **freeCodeCamp Responsive Web Design Certification**. This project serves as a clean, beginner-friendly reference guide covering core and modern CSS concepts with live code examples.

## Live Demo
[View Live Project](https://khushibuilds-dev.github.io/freecodecamp-technical-documentation/)

## Topics Covered
* **Typography:** Font families, sizing, weights, line height, letter spacing, and text decoration.
* **CSS Position:** Document flow behavior across `static`, `relative`, `absolute`, `fixed`, `sticky`, and `z-index`.
* **CSS Flexbox:** One-dimensional layouts using `flex-direction`, `justify-content`, `align-items`, `flex-wrap`, and `gap`.
* **CSS Grid:** Two-dimensional layouts using `fr` units, `repeat()`, `grid-template-areas`, and responsive `auto-fit`.
* **CSS Transitions:** Smooth hover animations and shorthand transition syntax.
* **CSS Animations:** Keyframe animations (`@keyframes`) including spinning loaders, bouncing elements, and pulse effects.
* **Media Queries:** Responsive breakpoints (`min-width` and `max-width`) for mobile, tablet, and desktop views.
* **CSS Variables:** Global (`:root`) and local custom properties (`var()`) for easy theme management.
* **CSS Units:** Differences and use cases for `px`, `%`, `rem`, `em`, `vw`, and `vh`.

## Technologies Used
* **HTML5** (Semantic structure with `<nav>`, `<main>`, and `<section>`)
* **CSS3** (Flexbox, CSS Grid, Custom Properties, and Media Queries)
